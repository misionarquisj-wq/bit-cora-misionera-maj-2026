Archivos que debes subir a GitHub Pages:
- index.html
- style.css
- script.js
- sw.js
- manifest.webmanifest
- carpeta images completa

No subas las carpetas _renders ni images/extracted: son materiales de trabajo y no forman parte del sitio final.

Para GitHub Pages, conserva exactamente la misma estructura de carpetas.
El funcionamiento offline se activa mediante sw.js después de que la página se haya cargado al menos una vez desde GitHub Pages.
