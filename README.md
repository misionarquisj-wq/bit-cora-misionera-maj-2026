# Bitácora Misionera MAJ 2026

Web estática/PWA lista para GitHub Pages. No utiliza APIs, CDNs, fuentes ni recursos externos.

## Publicar
1. Subir todo el contenido de esta carpeta a un repositorio.
2. En GitHub: Settings → Pages → Deploy from a branch → `main` / root.
3. Abrir la URL una vez con conexión para que el Service Worker guarde todos los archivos. Luego funciona offline.

## Fuente y fidelidad
El proyecto conserva las 33 páginas del PDF como reproducciones visuales locales en `images/pdf/`, además de organizar el texto disponible en secciones prácticas. Las páginas 28–33 se duplican en `images/mapas/` para acceso directo.
